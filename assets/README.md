# Assets Folder

This folder contains media assets for the Medical Tetris game.

## Files

- `gameplay.gif` - Gameplay demonstration GIF for README

## Creating the Gameplay GIF

To create the gameplay GIF:

1. **Using ScreenToGif (Windows)**:
   - Download from https://www.screentogif.com/
   - Record 10-15 seconds of gameplay
   - Edit and optimize
   - Save as `gameplay.gif`

2. **Using LICEcap (Mac/Windows)**:
   - Download from https://www.cockos.com/licecap/
   - Record gameplay
   - Save as `gameplay.gif`

3. **Using Peek (Linux)**:
   - Install: `sudo apt install peek`
   - Record gameplay
   - Save as `gameplay.gif`

4. **Using Online Tools**:
   - Use Chrome extension "Screencastify"
   - Export as GIF
   - Optimize with https://ezgif.com/optimize

## Recommended GIF Settings

- **Size**: 600-800px width
- **Frame Rate**: 15-20 FPS
- **Duration**: 10-15 seconds
- **File Size**: < 5MB (for GitHub)
- **Content**: Show starting game, playing, clearing lines, level up
